# UI/UX Design System Skill

## Purpose
Ensures application interfaces follow accounting conventions, use plain terminology, and maintain clean visual hierarchy.

## Key Guidelines
- Use domain terminology: "Create Invoice", "Record Payment", "GST", "Outstanding Balance".
- Tables built with TanStack Table with clear column headers, alignment (numbers right-aligned), and responsive pagination.
- Avoid unnecessary popups, vague action names, or cluttered elements.
