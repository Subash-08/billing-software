# PDF & Template Engine Skill

## Purpose
Governs modular invoice printable/downloadable layout engines for standard and E-Invoice documents.

## Configuration Tokens
- Logo visibility & placement
- Header/Footer text & legal disclaimers
- Column visibility (HSN/SAC, Discount, Tax %, Tax Amount)
- Bank details & UPI QR Code display
- Signatory image rendering

## Forbidden Practices
- NEVER hardcode invoice HTML into a single monolithic string or UI component.
